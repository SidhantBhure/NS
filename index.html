DESIGN AND DEVELOPMENT OF A CLASSICAL CRYPTOGRAPHY TOOLKIT

Mini Project Report Submission | Network Security & Cryptography Course

1. Objectives

To design, develop, and test a menu-driven software application implementing classical substitution and transposition ciphers, providing real-time text encryption, decryption, structural visualizers, and algorithm performance comparisons.

2. Implemented Algorithms & Modules

  • Substitution Ciphers: Caesar Cipher, Monoalphabetic Cipher, Playfair Cipher (5x5 Grid), Hill Cipher (2x2 Matrix), Vigenère Polyalphabetic Cipher, One-Time Pad.
  • Transposition Ciphers: Rail Fence Cipher, Columnar Transposition Cipher.
  • Utility Modules: Compare Algorithms Benchmark Engine, Text File Encryption/Decryption, Step-by-Step Structural Visualizers, Educational Theory Hub.

3. System Requirements

Client-side web technology stack utilizing standard Web Crypto API and modern DOM rendering engines. Fully operational in any standard HTML5 browser without requiring server-side software installations.
